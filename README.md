# カラーパレットメーカー

ブラウザだけで使える、無料のカラーパレット作成ツールです。
Web サイトやデザインに使える配色を、すぐに作れます。

**▶ ツールを使う：https://20se055.github.io/color-palette-maker/

インストールや登録は必要ありません。

## 使い方

1. 「ベース色」で好きな色を選ぶ（カラーピッカー、または `#FF8FB8` のような16進数で入力）
2. 「配色ルール」を選ぶ
3. 気に入るまで `Space` キー（または「生成」ボタン）を押す
4. 気に入った色は鍵アイコンで固定しておくと、作り直してもその色が残ります
5. できたパレットは、コピーしたり保存したりして使えます

## できること

### パレットを作る
- 配色ルールは8種類：類似色・補色・トライアド・テトラード・スプリット補色・モノクローム・パステル・ランダム
- 色の数は2〜8色から選べます
- 色ごとに固定・色の変更・コピー・削除ができます

### 色を確かめる
- **コントラスト比**：白文字・黒文字にしたときの読みやすさを数値で表示します（4.5以上が目安）
- **シェード**：各色を9段階に明るく・暗くした色を表示します。クリックでコピーできます
- **プレビュー**：パレットをボタンやカードに当てはめると、どんな雰囲気になるかを確認できます

### パレットを使う
- **コードとしてコピー**：CSS 変数・SCSS・JSON・配列の形式に対応しています
- **共有リンク**：今のパレットを開けるリンクをコピーできます
- **PNG で保存**：パレットを画像として保存できます

### パレットを集める
- **自分のパレット**：名前を付けて保存できます。名前を空欄にすると、色に合わせた名前をおまかせで付けます（ときどきおもしろい名前になります）
- **ひらめきパレット**：859個の名前付きパレットから、ランダムに6個表示します。季節・食べ物・街・レトロ・宇宙など、いろいろなテーマがあります。「シャッフル」で入れ替わり、クリックすると編集画面に読み込めます

## キーボード操作

| キー | 動作 |
|---|---|
| `Space` | 新しいパレットを生成 |
| `Enter`（16進数の入力欄で） | 入力した色をベース色にする |
| `Enter`（パレット名の入力欄で） | パレットを保存 |

## データの扱いについて

- 保存したパレットは、お使いのブラウザの中（localStorage）にだけ保存されます。サーバーに送られたり、他の人に見られたりすることはありません。
- ブラウザのデータを消したり、別の端末やブラウザで開いたりすると、保存したパレットは表示されません。
- 共有リンクに入るのは色の情報だけです。パレット名は含まれません。
- 外部から読み込んでいるのは、表示用のフォント（Google Fonts）だけです。

## 動作環境

Chrome・Edge・Safari・Firefox の最新版でのご利用をおすすめします。スマートフォンの表示とダークモードにも対応しています。
